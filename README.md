# 八雲ノ太刀 — 須佐之男と八岐大蛇

**[ブラウザで遊ぶ](https://kg-ninja.github.io/SUSANOWO/)**

須佐之男命が刀を携え、出雲の森と祠を抜けて八岐大蛇を討つ、横スクロールの和風ダークファンタジー剣戟アクション。
滑らかな足運びと重心移動、断崖と罠、一羽のカラス、八本の首との戦い、奉納から結末までを収録しています。
FM音源BGMと効果音はゲーム中に合成します。

「誓いの旅へ」で自分で操作。「演武を見る」で全編を自動観戦できます。
「ゆったり」では受ける傷が浅くなります。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | ← / →、A / D |
| 三連斬 | J / Z |
| 居合 | K / X |
| 受け・受け流し | Shift |
| 回避 | L / C |
| 跳躍 | Space / ↑ / W |
| 荒魂・天雷 | Q / U |
| 酒を捧げる | E / F |
| 一時停止 | P / Esc |

スマートフォンでは左手で移動、右端の大きな「跳」でジャンプします。移動を押したまま別の指でジャンプでき、右側の「斬」で攻撃します。補助の剣術と奉納は別の列に配置しています。横向き・全画面でもボタンが見えるように調整しています。
音声は開始ボタンを押すと鳴り始め、画面右上の「音」で切り替えられます。

## 開発・ローカル起動

HTML、CSS、JavaScript、Canvas 2D、Web Audioで実装。追加パッケージの導入は不要です。

```sh
python -m http.server 8000
```

`http://localhost:8000/` を開いてください。
`yakumo-no-tachi.html` はCSSとJavaScriptを埋め込んだ単体版で、ダウンロードして直接開くこともできます。

```sh
node test-game.js
python build.py
```

`engine.js` は戦闘・物語・敵AI、`animation.js` は姿勢と関節、`view.js` は描画と演出、
`audio.js` は音源、`app.js` は入力と画面、`style.css` はUIです。

## GitHub Pages

公開元は `main` ブランチのルート `/`。`.nojekyll` を置き、静的ファイルをそのまま配信します。
ゲーム本体の参照は相対パスなので、`/SUSANOWO/` 配下で起動できます。

## 確認済みの動作

ゲームロジックの自動テストで、戦闘、加速・減速・方向転換、30 / 60 / 120 Hzの接地、跳躍・着地、落下と罠、カラスの撃退を確認しています。
通常・ゆったりの自動演武では六つの障害・カラス・八頭の大蛇を越え、奉納と結末まで到達しました。
完成版を実際のChromiumで起動し、ゲーム内BGM・効果音付きの全編演武を録画しています。
タッチ配置の更新では、320 / 390pxの縦画面と844 / 1024pxの横画面で、移動を保持した二本指のジャンプ・攻撃・指の解放を確認しました。全画面でも操作ボタンがゲーム画面と重ならず、キーボード操作も確認済みです。
